# v1.3.0 独立播报运行程序

生成器将自行编写的 `IndependentAnnouncer.cs` 编译结果重新命名为用户的语音包名字，用 Mono.Cecil 嵌入配置与 PCM WAV。生成的 ZIP 只有 Everest 清单、一个模块 DLL、说明和制作信息；不修改任何第三方模块，不复制任何 `.bank` 元数据。不需要模板、FMOD Studio、游戏文件或额外音频库来生成。

模块监听 Everest 的游戏 Hook，调用原方法一次，再根据游戏状态决定是否播报。没有音频的项目直接返回。每个项目有 1–5 条时独立等概率随机选择，允许重复抽中。

## 检测依据

| 事件 | 依据 |
| --- | --- |
| Demo Dash | 一次新的冲刺事件，方向水平，正在下蹲或游戏的 `demoDashed` 标记为真；重复冲刺回调忽略 |
| Super | 游戏调用 `SuperJump`，跳前未下蹲 |
| Hyper | 游戏调用 `SuperJump`，跳前下蹲，且不满足 Wavedash 条件 |
| Wavedash | 下蹲 `SuperJump`，本次冲刺从空中开始、初始方向斜向下；落地压平方向时保留原始瞄准方向 |
| Wall Bounce | 游戏调用 `SuperWallJump` |
| Neutral Jump | 游戏调用 `WallJump`，调用前水平输入为零 |
| Corner Boost | 空中向面朝方向移动，抓墙跳前上方六像素没有实墙，原调用后增加了水平速度并向上跳 |
| Ultra | 斜下冲刺落地，原调用实际增加了至少约 10% 水平速度，进入碰撞前水平速度高于普通冲刺在该方向上的分量；每次冲刺只报一次 |
| Fast Bubble | 绿色泡泡的 `BoostUpdate` 返回普通冲刺状态；红泡泡和等待状态不报 |
| 普通/带金死亡 | 原死亡调用返回尸体，且此前尚未死亡；调用前从跟随对象中检查金草莓 |
| 普通/金草莓收集 | 原调用使草莓从未收集变为已收集；同一对象不重复播报 |

检测是本项目的独立规则，不承诺与旧模板所有边界条件一致。兼容原版玩家和草莓及继承其标准行为的对象；其他模组重写动作、泡泡或收集流程时需要单独验证。特别是抓角、慢速 Ultra、变体速度、特殊地形，可能需要根据游戏内测试调整。

## 播放与生命周期

运行时从自己的程序集读取 WAV，通过游戏已有的 FMOD Core 创建内存声音，播放到 `bus:/gameplay_sfx`。因此沿用游戏的音效音量和暂停处理，不建立另一套音频系统。首次锁定总线后刷新 Studio 命令，确保第一条声音也有可用的播放组。

语音懒加载并缓存，最多缓存所选的 65 个声音；同时播放最多八条，超过时结束最早的一条。模块音量可设为 0–10；禁用后停止当前语音。卸载时移除所有 Hook、停止声音、释放缓存并解锁总线。不同语音包有不同程序集身份和资源，每个包的设置、随机数及缓存独立。多个播报包同时开启会各自播报，建议只开启一个。

v1.2.0 生成的语音包仍含旧运行程序。迁移时请用 v1.3.0 重新生成并替换同名 ZIP，然后重启游戏；仅更新生成器不会改变已经生成的模组。
